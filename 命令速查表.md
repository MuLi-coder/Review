# 一、速查表

## 1. 基本命令

|   用途    |           PowerShell           | 参数备注                                                                                      | Linux | 参数备注                                                                    |
| :-----: | :----------------------------: | ----------------------------------------------------------------------------------------- | :---: | ----------------------------------------------------------------------- |
|  切换目录   |     `cd` / `Set-Location`      | 1. `..` ：上一级文件夹<br>2. `.` : 当前文件夹<br>3. `-Path <路径>` ：绝对路径<br>4. `<路径>`：直接加路径             | `cd`  | 同左                                                                      |
| 获取目录下条目 | `ls` / `dir` / `Get-ChildItem` | 1. `-r` / `-Recurse` ：递归列出所有子目录内容<br>2. `-Force` ：显示包含隐藏文件<br>3. `-Filter <key>` ：按照文件名过滤 | `ls`  | 1. `-l`：长格式显示<br>2. `-a` ：显示隐藏文件<br>3. `-R` ：递归显示<br>4. `-h` ：人类可读文件的大小 |
|  复制文件   |       `cp` / `Copy-Item`       | 1. `-r` / `-Recurse` ：递归复制，文件夹复制必须加                                                       |       |                                                                         |
|  移动文件   |       `mv` / `Move-Item`       |                                                                                           |       |                                                                         |
|  创建文件   |      `mkdir` / `New-Item`      | 1. `-r` / `-Recurse` ：递归删除，删除文件夹必加                                                        |       |                                                                         |
|  删除文件   |  `rm` / `del` / `Remove-Item`  |                                                                                           |       |                                                                         |
